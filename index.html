我是 徐弘轩，目前就读于 沈阳理工大学 计算机科学与技术专业，大二。

说实话，我是被录进这个专业之后才开始真正接触编程的——起点不算早，也谈不上什么天赋型选手。 但学着学着发现，能让一段代码跑起来、能亲手把一个想法变成看得见的东西，这件事本身就挺让人上瘾的。 既然已经在这条路上了，那我就打算全心把它学好。

目前我在系统补 Python 和 C / C++ 的基础， 也在用 Arduino 和 Keil5 碰一碰单片机， 同时习惯借助 AI 工具边做边学，把不懂的地方一个个啃下来。 接下来最想做的事，是真正参与进项目里，用实战检验自己到底学到了多少。
